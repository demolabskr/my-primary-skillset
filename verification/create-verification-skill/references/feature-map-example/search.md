# 노트 검색

사용자는 제목이나 본문 글자로 노트를 찾고, 일치하는 노트를 열어 보고, 결과가 없는 상태와 검색을 쓸 수 없는 상태를 구별할 수 있다.

## 세부 기능

- `search-open`: 브라우저의 각 진입 경로에서 검색을 연다.
- `search-match`: 노트 데이터를 바꾸지 않고 제목·본문 일치 결과를 돌려준다.
- `search-open-result`: 결과를 눌러 노트 편집기에서 연다.
- `search-empty`: 일치하는 노트가 없는 검색어에 안내 문구까지 갖춘 빈 상태를 보여 준다.
- `search-clear`: 검색어를 지우고 최근 노트 화면으로 돌아간다.
- `search-cli`: 터미널에서도 같은 일치 결과를 돌려준다.

## 들어가는 길 (사용자 관점)

- 브라우저 툴바에서 `검색` 버튼을 누른다.
- 브라우저에서 입력란 밖에 포커스가 있을 때 `/`를 누른다.
- 터미널에서 `notes search <검색어>`를 실행한다.

## agent-browser로 조작하기

전제 조건:

- Notes가 `http://127.0.0.1:4173`에서 정상이다.
- 임시 데이터 폴더에 본문이 `예산 초안`인 `분기 계획` 노트가 있다.
- 점검(Doctor)이 기대한 URL과 데이터 폴더를 보고한다.
- 실행 환경 파일을 `source`했다(`S`, `E`, `ab`).
- `F="$E/search"; mkdir -p "$F"`를 실행했다.

- **툴바로 열기.** `검색` 버튼을 누른다. `ab find role button click --name "검색"`을 실행한다. 이름이 `노트 검색`인 대화상자가 나타나고 검색란에 포커스가 있다.
- **키보드로 열기.** 대화상자를 닫고 페이지에 포커스를 둔 뒤 `/`를 누른다. `ab press Escape`와 `ab press /`를 실행한다. 같은 대화상자가 나타나고 페이지에 `/`가 입력되지 않는다.
- **제목 일치.** `분기`를 입력한다. `ab fill 'input[aria-label="노트 검색"]' "분기"`와 `ab wait --text "분기 계획"`을 실행한다. `검색 결과` 목록에 `분기 계획`이 있고 `장보기 목록`은 없다.
- **본문 일치.** 검색어를 `예산`으로 바꾼다. `ab fill 'input[aria-label="노트 검색"]' "예산"`을 실행한다. `분기 계획` 결과가 본문 일치 발췌와 함께 남아 있다.
- **결과 열기.** `분기 계획`을 누른다. `ab find text "분기 계획" click --exact`를 실행한다. 대화상자가 닫히고 편집기 제목이 `분기 계획`이다.
- **결과 없음.** 검색을 다시 열고 `화산`을 입력한다. `ab fill 'input[aria-label="노트 검색"]' "화산"`과 `ab wait --text "일치하는 노트가 없습니다"`를 실행한다. 검색이 끝난 뒤 그 상태 메시지가 나타난다.
- **검색어 지우기.** `검색어 지우기`를 누른다. `ab find role button click --name "검색어 지우기"`를 실행한다. 검색란이 비고, 결과 목록 대신 `최근 노트` 영역이 나온다.
- **CLI 일치.** 터미널에서 검색한다. `notes search "분기" --format json > "$F/cli-match.out" 2> "$F/cli-match.err"; echo $? > "$F/cli-match.exit"`를 실행한다. 종료 코드는 `0`이고 stdout에 제목이 `분기 계획`인 객체 하나가 있다.
- **CLI 결과 없음.** 없는 값을 검색한다. `notes search "화산" --format json > "$F/cli-miss.out" 2> "$F/cli-miss.err"; echo $? > "$F/cli-miss.exit"`를 실행한다. 종료 코드는 `0`이고 stdout은 `[]`이다.
- **증명.** 결과가 채워진 상태를 남긴다. `ab snapshot > "$F/results.aria.txt"`와 `ab screenshot --annotate "$F/results.png"`를 실행한다. 두 증거에 Notes, 검색어, `분기 계획`이 보인다.

## 함정

- 편집기나 검색란에 포커스가 있을 때 `/`를 누르면 검색이 열리지 않고 글자가 입력된다.
- 결과는 짧은 지연 뒤에 갱신된다. 고정 `sleep` 대신 결과 목록이나 빈 상태 메시지를 기다린다.
- 보관한 노트는 `보관함 포함`을 켜야 결과에 나온다.
- CLI 기본 출력은 사람이 읽는 형식이다. 안정적으로 확인하려면 `--format json`을 쓴다.
- 결과를 열면 브라우저 상태가 바뀐다. 다른 검색어를 증명하기 전에 검색을 다시 연다.
